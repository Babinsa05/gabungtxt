Panduan Lengkap

1. Upload File / Folder — Klik “Pilih File TXT” atau “Pilih Folder”, atau drag & drop area biru. Semua file .txt langsung terdeteksi.
2. Otomatis Bersih & Sortir — Sistem hapus baris duplikat, lalu mengurutkan berdasarkan tanggal (YYYY-MM-DD, DD/MM/YYYY, dll). Baris tanpa tanggal akan di akhir.
3. Deteksi Nama Desa & Bulan — AI internal membaca nama file dan konten. Nama desa diekstrak dari pola "Desa X" atau nama file, bulan diambil dari tanggal terbanyak.
4. Download & Copy — Tombol hijau simpan sebagai .txt, hasil siap diimpor ke Word atau Excel.
Tips: Gunakan folder untuk laporan bulanan, nama file bisa mengandung "Desa_Sukamaju", program akan mendeteksi otomatis.
📌 Pastikan file .txt berisi satu entri per baris, dengan tanggal di awal baris untuk sorting sempurna.

Cara Copy ke Microsoft Word

1. Hasil sudah rapih — Setelah file tergabung, klik Ctrl+A di area output, lalu Ctrl+C.
2. Buka Word → Paste dengan Ctrl+V (pilih 'pertahankan teks asli')
3. Format cepat: Gunakan 'Tabel Konversi Teks ke Tabel' jika data menggunakan pemisah tab/spasi rapi.
Tips rapi : Sebelum copy, pastikan font di Word monospace (Courier New) untuk alignment sempurna.
